# API v2（证书业务接口）

供下游接入方对接证书申请、续费、重签、取消、查询与验证文档上传。

- **Base URL**：`{站点地址}/api/v2`
- **鉴权**：请求头 `Authorization: Bearer {API Token}`（在「设置 → API」获取）
- **统一响应**：`{ "code": 1|0, "msg": "", "data": {...}, "errors": null }`，`code=1` 成功、`code=0` 失败
- **不支持** `delegation`（委托）验证方法

## 端点一览

| 方法 | 路径                        | 说明                               |
| ---- | --------------------------- | ---------------------------------- |
| GET  | `/health`                   | 健康检查                           |
| GET  | `/get-products`             | 产品列表（含会员价）               |
| GET  | `/get-orders`               | 订单列表（分页）                   |
| POST | `/new`                      | 申请证书                           |
| POST | `/renew`                    | 续费                               |
| POST | `/reissue`                  | 重签                               |
| GET  | `/get`                      | 订单详情（含 dcv/validation/证书） |
| GET  | `/get-order-id-by-refer-id` | 用 refer_id 反查订单 ID            |
| POST | `/cancel`                   | 取消订单                           |
| POST | `/revalidate`               | 重新验证                           |
| POST | `/update-dcv`               | 修改验证方法                       |
| GET  | `/download`                 | 下载证书                           |
| POST | `/upload-document`          | 上传验证文档（Certum OV/EV）       |

## 申请 `POST /new`

| 参数                       | 必填  | 说明                                                       |
| -------------------------- | ----- | ---------------------------------------------------------- |
| `product_code`             | 是    | 产品编码（见 get-products）                                |
| `period`                   | 否    | 周期（月），默认按产品                                     |
| `domains`                  | 是    | 域名，逗号分隔                                             |
| `validation_method`        | 是    | `dns` / `txt` / `file` / `email` 等（**不含 delegation**） |
| `csr_generate`             | 否    | 1=系统生成，0=用 `csr`                                     |
| `csr`                      | 否    | `csr_generate=0` 时必填                                    |
| `contact` / `organization` | OV/EV | 联系人 / 企业信息对象                                      |
| `refer_id`                 | 否    | 端到端幂等键（≤64）                                        |
| `issue_verify`             | 否    | 1=提交后立即尝试验证                                       |

返回 `data`：`{ order_id, cert_apply_status, dcv, validation }`。`renew` 同参 + `order_id`；`reissue` 取 `order_id` + csr/domains/organization。

## 查询 `GET /get?order_id=`

返回订单与证书：`common_name`、`alternative_names`、`dcv`、`validation`、`csr`、`private_key`、`cert`、`issued_at`、`expires_at`、`status` 等。`get` 会顺带触发待支付/待提交/可同步订单的推进。

## 取消 / 重新验证 / 改验证 / 下载

- `POST /cancel`：`{ order_id }`
- `POST /revalidate`：`{ order_id }`
- `POST /update-dcv`：`{ order_id, method }`（不支持 delegation）
- `GET /download?order_id=&type=all|certificate|...`

## 上传验证文档 `POST /upload-document`

Certum 系 OV/EV 需上传验证材料。

| 参数               | 必填 | 说明                                                          |
| ------------------ | ---- | ------------------------------------------------------------- |
| `order_id`         | 是   | 订单 ID                                                       |
| `type`             | 是   | `APPLICANT` / `ORGANIZATION` / `AUTHORIZATION` / `ADDITIONAL` |
| `fileName`         | 是   | 文件名（含扩展名，PDF/JPG/PNG/XADES，≤5MB）                   |
| `document_content` | 是   | 文件内容 base64                                               |

> **幂等去重**：同一订单下相同内容只存一份（按内容哈希），重复上传安全。上传后异步入队提交上游，可重复调用查询接口观察状态。

## 示例

```bash
curl -X POST "{站点地址}/api/v2/new" \
  -H "Authorization: Bearer {API Token}" \
  -H "Accept: application/json" \
  -d "product_code=xxx" -d "domains=example.com" \
  -d "validation_method=dns" -d "csr_generate=1"
```
